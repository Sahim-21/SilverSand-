# Silver Sand Beach Homestay

Direct-booking website for **Silver Sand Beach Homestay**, Murudeshwar, Karnataka (`silversandhomestay.com`).

Guests pick occupancy and dates, see a **live estimate from the owner’s prices**, and tap **Check Availability on WhatsApp** (or call). Occupancy rates are not hardcoded — the owner edits them in a small admin panel.
